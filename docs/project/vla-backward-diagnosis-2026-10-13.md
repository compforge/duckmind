# 后退：语言敏感性与闭环偏离诊断

用户授权继续学习后退。先用v19固定checkpoint解释失败，本轮不更新权重、不新增训练数据。
同一模型在熟悉文字下后退并失稳、在留出文字下原地稳定；这可能由不同机制导致。

## 问题与选择

| 选择 | 预期区分 | 本轮 |
|---|---|---|
| 同一老师状态换文字 | 语言条件对动作拟合的影响 | 执行 |
| 分阶段拟合与逐关节误差 | 起步拟合好但步态后期误差大 | 执行 |
| 训练初态与旧失败重现 | 已有轨迹也失败，还是初态变化后失败 | 执行 |
| 调整采样或补纠偏 | 改善拟合或扩展闭环覆盖 | 待上述证据，不预先开训练 |
| 改模型/损失/解冻语言塔 | 改变表达能力或语言适配 | 当前无隔离证据，暂不改 |

诊断先验（主观、非统计后验）：稀疏步态拟合/闭环偏移40%、语言条件泛化30%、
多任务采样与干扰15%、训练/评估实现缺陷5%、未知10%。独立检查token序列长度7/8/15，
均小于48且不同，暂不支持截断或碰撞；VLM冻结不意味着文本嵌入没有区分能力。

  前者虽在采集目录定义中，但未选入训练；后者已用于v19评估，不是全新测试。
- 错目标控制：保持站立、向前走。共216个配对预测，另1个相同输入重复smoke。
  保存原始state/prior/target/chunk、第一步/执行前5步/H10误差、逐关节误差、persistence。
- 使用原evaluate复现body730/731两种措辞，增加训练body700两种措辞，共6条。
  原evaluate另有22个训练集fit探针；不增加训练。比对旧失败的实际输入/动作/物理状态。
- 第一组输入保存原生processor张量（token、mask、归一化state、blackimage）。
  它是同一输入的预处理重建；独立CPU审查确认与实际predict使用同一processor。

相同输入smoke应完全相等；旧730/731应重现，若未重现保留差异并先调查。
216个预测不等于216个独立轨迹或重复训练。当前checkpoint的误差不能证明继续训练带来的因果效果。
若canonical在老师状态上已优于persistence但身体闭环仍失败，优先调查状态分布偏移；
若第二训练说法或后期步态本身拟合差，先解决拟合/覆盖，而不是一概加同义句。
错误目标的MSE不是该目标本身正确性的评估；姿态相近也可能使其误差低。
